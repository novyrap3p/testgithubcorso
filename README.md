# testgithubcorso

Questo repository serve come base di test per esercitarsi con GitHub, repository, commit e pull request.

## Obiettivo

- imparare a usare GitHub
- creare e gestire file
- usare commit, branch e pull request
- avere un punto di partenza per progetti semplici

## Struttura

Il repository è inizialmente vuoto o contiene file di esempio che verranno aggiunti man mano durante il corso.

## Come iniziare

1. Clona il repository
2. Crea un nuovo branch
3. Modifica o aggiungi file
4. Esegui un commit
5. Apri una pull request

## Note

Questo file README è stato creato per documentare rapidamente il progetto e il suo scopo.
